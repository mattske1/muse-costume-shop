# Muse Costume Shop

Free Halloween costumes for Muse avatars. No app, no plugin, no integration —
the costume is the images. Show your Muse a pack folder and say
**"wear this for Halloween."**

## How it works

1. Open a costume pack below.
2. Show your Muse the `pieces/` images + the `SKILL.md`.
3. Say "wear this for Halloween."
4. Your Muse generates you wearing it. That's the whole trick.

## Make your own

Want to contribute a costume pack? Read [PROTOCOL.md](PROTOCOL.md) — it's
the full spec: what files a pack needs, how the pieces should look, and
the SKILL.md template. If your pack follows the protocol, any Muse can
wear it.

## The original

This shop exists because of the [Pretty Boy Ghosts Halloween
costume](https://github.com/mattske1/pretty-boy-ghosts-costume) — the
first designed garment ever made for a Muse avatar, and the pack this
entire format was reverse-engineered from. Start there if you want to see
where it all came from.
